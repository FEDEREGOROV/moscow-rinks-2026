# Катки Москвы: каталог и сравнение

Статический сайт для руководства «Лужников». Два раздела: каталог организованных катков Москвы и сравнительная таблица. Состояние данных: **26 ноября 2026 года**.

Каталог включает 34 площадки, для которых найдена официальная страница оператора или городской документ. Для каждой указаны статус, адрес, опубликованные часы, входной билет, прокат и ссылка на первоисточник. В карточках приведены подробные тарифы сезона 2026/27, дополнительные услуги, официальные фотографии и социальные сети там, где они опубликованы. У ГУМ-катка приведены все строки официальных тарифных таблиц по трём периодам сезона.

Цены предыдущих сезонов не выданы за действующие. «Не опубликовано» означает, что тариф 2026/27 не подтверждён по указанному официальному источнику. Фотографии предыдущих сезонов помечены. Если подтверждённой фотографии нет, карточка остаётся без изображения.

## Файлы

- `index.html` — каталог.
- `analysis.html` — сравнительная таблица.
- `rinks-data.js` — площадки, ссылки и опубликованные сведения.
- `gum-tariffs.js` — полная тарифная сетка ГУМ-катка из официального API.
- `script.js`, `analysis.js` — интерфейс.
- `styles.css` — оформление.

Открыть `index.html` в браузере или разместить содержимое папки в корне GitHub Pages.
