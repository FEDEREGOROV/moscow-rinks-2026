# Катки Москвы: каталог и сравнение

Статический сайт для руководства «Лужников». Три раздела: каталог организованных катков Москвы, сравнительная таблица и карта. Состояние данных: **26 ноября 2026 года**.

Каталог включает 59 площадок, для которых найдена официальная страница оператора или городской документ. Для каждой указаны статус, адрес, опубликованные часы, входной билет, прокат и ссылка на первоисточник. В карточках приведены подробные тарифы сезона 2026/27, дополнительные услуги, официальные фотографии и социальные сети там, где они опубликованы. У ГУМ-катка приведены все строки официальных тарифных таблиц по трём периодам сезона.

В сравнительной таблице показаны первые тарифные позиции, ссылки на официальные фото и социальные сети. Кнопка «Все сведения» раскрывает полные опубликованные тарифы и условия конкретного катка. Поиск охватывает также цены и сведения оператора.

Карта показывает те же 59 площадок. Координаты сохранены в `rink-coordinates.js` после разовой сверки адресов с OpenStreetMap; сайт не обращается к геокодеру при открытии. Для площадок без точной точки входа маркер соответствует указанному адресу или территории, поэтому его положение приблизительное.

Цены предыдущих сезонов не выданы за действующие. «Не опубликовано» означает, что тариф 2026/27 не подтверждён по указанному официальному источнику. Фотографии предыдущих сезонов помечены. Если подтверждённой фотографии нет, карточка остаётся без изображения.

## Файлы

- `index.html` — каталог.
- `analysis.html` — сравнительная таблица.
- `map.html` — карта и список площадок.
- `rinks-data.js` — площадки, ссылки и опубликованные сведения.
- `rink-coordinates.js` — координаты для карты.
- `gum-tariffs.js` — полная тарифная сетка ГУМ-катка из официального API.
- `script.js`, `analysis.js`, `map.js` — интерфейс.
- `styles.css` — оформление.

Открыть `index.html` в браузере или разместить содержимое папки в корне GitHub Pages.
