# На лёд — обзор рынка катков Москвы 2026/27

Статический сайт для руководства Лужников. Две вкладки: фотокаталог 27 московских площадок и сравнительная таблица с тарифами, прокатом, позиционированием и SEO-рекомендациями. Данные проверены **26 ноября 2026 года**.

## Что внутри

- `index.html` — каталог катков.
- `analysis.html` — конкурентный анализ и SEO-выводы.
- `styles.css` — адаптивный дизайн.
- `script.js` — данные 27 катков, фотографии, поиск, фильтры и карточки.
- `analysis.js` — сравнительная таблица всех площадок.

Откройте `index.html` в браузере или запустите локальный сервер: `python3 -m http.server 8000`.

## Обновление данных

Записи находятся в массиве `rinks` в `script.js`. Для каждой площадки укажите актуальные цену, дату открытия, статус `open`, адрес источника, описание тарифов `details` и условия проката `rental`. Если тариф неизвестен, оставьте `price: null`. Статусы «открыт» зафиксированы на 26 ноября 2026 года и требуют ручного обновления.

У 25 площадок показаны архивные фотографии со ссылкой на источник в подробной карточке. Для Старопетровского проезда и хоккейной коробки «Северное сияние» проверенное изображение не найдено, поэтому там показана графическая заглушка. Внешние изображения загружаются со сайтов источников; их доступность зависит от этих сайтов. Перед использованием фотографий в рекламных материалах уточните права у правообладателей.

Большинство районных цен и дат взяты из [обзора Сравни от 24 ноября 2026 года](https://www.sravni.ru/novost/2026/11/24/gde-katatsya-na-konkah-v-moskve-zimoj-2026-27/); они обозначены на сайте как данные обзора. Для Лужников, ВДНХ, Парка Горького, ГУМ-катка и Северного речного вокзала дополнительно проверены официальные страницы операторов. Каталог не включает все дворовые и временные катки: официальный полный реестр сезона на дату проверки не опубликован.

## Публикация

Загрузите файлы в корень публичного репозитория на GitHub. В **Settings → Pages → Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`. GitHub Pages будет публиковать изменения после каждого коммита в `main`.
